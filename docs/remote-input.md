# 电视统一手机输入

从 WebDAV、源配置、UA、MPV 配置、弹幕接口设置或推送页扫描二维码，在手机浏览器中收藏该页面。后续直接打开收藏，在电视上进入要填写的原生输入框，即可在手机上发送文字，无需逐字段扫码。页面不回读电视中的旧值。

覆盖继承电视 BaseActivity、BaseAlertDialog、BaseBottomSheetDialog 的原生 EditText，以及 WebDAV 的配置弹窗。搜索关键词、源地址、WebDAV 地址/账号/密码等使用同一入口。网页内部的登录框和 Android 系统键盘弹窗不在此接收范围内；推送页提供通往原有搜索、播放推送、遥控器页面的链接。

WebDAV 密码在电视设置行、电视编辑框和手机输入框中直接显示。其他标记为密码的原生字段在手机上仍使用密码框。所有字段仅写入当前编辑框，确认、保存、搜索仍在电视端进行。

连接密钥单独保存在本机 SharedPreferences，不纳入 WebDAV 同步；应用重启、升级后保留。清除应用数据、卸载或在电视上长按二维码重置连接后，旧链接失效。密钥在 URL 中，请勿分享。手机和电视需在同一局域网；电视 IP 或 HTTP 端口变化时旧地址无法自动发现新地址，需重新扫码，建议在路由器上为电视固定 DHCP 地址。

手机草稿绑定当前输入框版本。电视切换输入框时，旧草稿禁止发送，点击“切换到电视当前输入框”清空草稿后再输入。服务端在主线程再次核对接收目标，窗口关闭或目标改变时拒绝写入。请求在读取正文前校验密钥、方法、类型和长度；页面及状态响应禁止缓存，不返回已保存的文字或密码。HTTP 仅适用于可信局域网。

验证：

- `node --test tools/remote-input-tests/page.test.cjs` 验证连续输入、目标切换、密码展示和连接撤销。
- `JAVA_HOME=<JDK 路径> bash gradlew :app:assembleLeanbackRelease -PplayerCompat=true` 编译兼容播放器版，输出两种 ARM 架构。
- 真机需验证：扫码收藏 → WebDAV 地址/账号/密码连续填写 → 搜索、源配置复用同一页面 → 重启应用后复用 → 长按二维码后旧链接拒绝连接。

本地构建和脚本测试不能替代电视、手机及局域网的端到端验证。
