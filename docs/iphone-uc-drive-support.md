# iPhone UC 网盘接入

更新时间：2026-10-20。当前为本地候选实现，已通过同步 UC 登录态读取真实目录，但当前样本因 UC 客户端/会员播放限制未通过正片实播。

## 已接入

- 从 WebDAV 同步文档的 `catvod-sp-utils-v1` 账号记录读取 `prefs/defaults.uc_ck`；兼容插件加密文本，内存解码，不写入钥匙串。
- 夸克与 UC 的账号、接口主机、分享链接及播放路由分开处理。UC Cookie 不替代夸克 Cookie，不发送到影视站点或第三方媒体域名。
- UC 分享目录递归读取、分页、选集、转存任务及原画播放；复用现有 VLC、本地流代理和 AirPlay 链路。UC 转码清晰度尚未开放。
- 玩偶、聚剧、新6V、立播网盘详情、网盘镜像与盘搜结果识别 UC 分享；原有磁力及其他未适配网盘限制保持。
- 网盘账号页分别显示夸克、UC 的同步状态。没有 UC Cookie 时明确提示同步 UC 登录态。

## 协议依据

对照本地恢复的 Android 插件 `Cloud_uc`、`i3` 调用，以及 UC 官方分享网页加载的接口实现。分享授权为 `share/sharepage/token`，目录为 `share/sharepage/detail`，转存为 `share/sharepage/save`，原画为 `file/download`。Cookie 模式的下载请求采用原插件的 UC 浏览器请求头。
