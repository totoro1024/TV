# iPhone 直播对照 Android TV

## 已接入

- 首页直播入口直接读取当前直播配置的 `lives`，支持切换配置与配置内直播源，使用同一 WebDAV 源配置与直播收藏。
- M3U、TXT（`#genre#`）、JSON 分组频道列表；频道号、台标、名称、分组搜索；同频道多条线路与线路名称。
- 播放页上一/下一频道、频道列表、线路、直播源、音轨、字幕、源提供的自适应清晰度、横屏全屏与铺满；记录最后频道和线路。直播不显示点播的片头/片尾和无效进度条。
- HTTP 请求头保留到播放请求；HTTP/HLS 走 AVPlayer，RTSP/RTMP/UDP/RTP 及 FLV 走现有 VLC 内核。VLC 直播保留 UA/Referer，其他自定义头仍取决于内核支持。
- 直播线路明确报错或加载超时后自动尝试该频道尚未失败的其他线路，全部失败后保留错误供手动重试。
- XML/XMLTV、GZip XML 和 JSON 节目单，频道匹配、时区与跨日时间；节目日期选择；源提供的 default/append 回看模板。没有节目单或回看地址时明确显示，不伪造数据。
- 电视同步来的直播收藏按频道名称在当前直播配置中查找，不要求电视提供 iOS 专有站点编号。

## 验证边界

Android JAR、需要 Android 本机代理的地址、Widevine 等 Android DRM 与私有插件解密不能直接在 iOS 执行，需要单独适配。VLC 直播当前不能通过 AVPlayer 的 AirPlay 接收设备选择器投放，HLS 直播沿用直接 AirPlay。节目单及回看仅在源实际提供有效数据时可用。

点播配置中另有 49 个站点。直播功能与这些站点的点播插件是独立链路；全部点播插件尚未完成移植，当前已有豆豆、玩偶、茉莉等原生适配，不能据此宣称其他站点已支持。

自动化验证：86 个 Swift 测试，2 个原有可选网络测试跳过，0 失败；iPhoneOS 与 iPhone 模拟器构建通过。
