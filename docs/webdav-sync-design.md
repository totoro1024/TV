# WebDAV 同步设计访谈

## 已确认

- 基于 totoro1024/TV fork 开发。
- 同步观看记录、播放进度、收藏、影视源、直播源及通用偏好。
- 电视端和手机端均在范围内，用户进一步要求支持 iPhone。
- 每位用户使用独立同步目录。
- 同时支持手动和自动同步；启动、退出播放、收藏或配置变更时触发，失败保留本地数据并显示状态。
- 解码器、音量、界面布局等设备设置留在本机。
- 开发配套 iOS 应用，与 Android 端共享同步格式。
- 第一阶段先交付 Android 电视端，设计同步格式时考虑后续 iPhone 接入；iOS 客户端后续交付。
- 提供覆盖远端、覆盖本地、拉取合并、清空远端四种操作；其精确语义与自动同步行为待确认。
- 播放进度采用最近一次观看的位置，允许回看导致集数或进度倒退。
- 单条删除传播到其他设备；清空全部单独确认并提示跨设备影响。
- 首版仅在相同源、相同影片标识之间自动续播，不按片名跨源自动合并。
- 首版同步源地址与源偏好，不携带本地文件和插件；缺少文件时提示本机补充。
- 提供“立即同步”，执行拉取、合并、上传；自动同步使用相同流程。
- 清空远端后暂停本机自动同步；其他设备检测到远端重置后同样暂停，保留本地数据，由用户选择是否用本机重建云端或从云端重新开始。
- Q12 已确认：覆盖远端以本机数据替换云端，其他设备下次同步时应用；覆盖本地以云端数据替换本机；拉取合并只下载合并不上传；清空远端只清除此应用的同步数据。操作限定在同步范围，覆盖前保留恢复副本。
- 支持用户的 HTTP WebDAV 服务；不额外加密同步内容。连接凭据由应用内填写，不内置到安装包，也不记录在设计文档中。

## 设置与播放行为

- 同步当前影视源、当前直播源、源内默认站点和站点搜索开关。
- 播放器、解码、音量、字幕样式、界面、网络设置及 WebDAV 账号留在本机。
- 后续 iOS 暂不支持的设置保留在云端，避免客户端写回时丢失。
- 同步不打断正在进行的播放，合并后的进度在下次打开影片时使用。
- 播放中每 60 秒尝试上传进度；暂停与退出播放时也触发同步。
- 无痕观看不上传观看记录与播放进度；收藏及源配置照常同步，无痕开关由各设备独立控制。

## 第一阶段交付与验证

- Android 电视端提供 WebDAV 配置、连接测试、自动同步开关、最后同步状态、立即同步及四种高级操作。
- 同步格式独立于 Android 数据库，表达源身份、影片身份、播放进度、修改版本及删除记录，为 iOS 接入保留兼容空间。
- 对合并冲突、删除传播、覆盖、远端重置、断网与重试进行验证；有真实设备和服务的操作条件时再验证端到端行为。
- 编译成功、模拟服务验证与真机验证分别报告；iOS 应用不在第一阶段完成范围内。

## 确认状态

逐项设计与完整方案均已获用户确认，已进入实现。详细数据格式见 [同步协议](webdav-sync-protocol.md)。

## 已核实的源码约束

- FongMi/TV 为 Android 工程，mobile 构建并非 iOS 应用。
- History/Keep 引用了本机 Config.id；跨设备导入需要映射源身份和本机编号。
- 现有备份恢复先清空数据库，不能直接作为双向同步实现。
- 现有数据删除没有删除标记，仅合并现存条目会使已删除数据重新出现。

同步功能已进入实现与验证阶段，完成情况以验证记录为准。
