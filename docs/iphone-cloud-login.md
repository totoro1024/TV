# iPhone 统一扫码登录

入口：切换到「我的云盘｜配置」→ 点播 →「统一扫码登录」。设置中的网盘账号页也保留相同入口。进入配置页先显示入口，不自动弹窗。

- UC：原生二维码，通过 UC 官方 CAS 接口等待手机确认，再兑换网盘登录态。
- 夸克：加载官方网页登录，在应用内放大官网二维码；可切回完整网页。确认官方账号接口有效后才保存。
- 登录信息写入现有本地同步文档，不使用钥匙串。兼容 Android TV 的 `catvod-sp-utils-v1` 账号格式，保留其他网盘配置。
- 登录成功后立即尝试普通 WebDAV 合并同步，不依赖自动同步开关。未配置 WebDAV 或同步处于暂停状态时，保留本地登录并显示提示，不覆盖远端数据。
- 返回登录页上一级会停止等待；切换同步账号后，旧登录页不得写入新账号文档。二维码和授权令牌不写入日志、截图证据或源码。

已在 iPhone 18 Pro Max 验证模拟器确认配置入口、网盘选择和夸克放大二维码。UC 官方接口已真实取得二维码令牌，未扫码时返回等待授权。核心测试覆盖授权协议、Android 兼容编码、其他网盘字段保留、删除记录重建和有界 HTTP 解码。
