# 多用户使用同一 WebDAV 服务

Android TV 和 iPhone 均提供“用户目录”选填项，拼接在服务器目录地址后，不改变原有同步文件格式；留空沿用旧地址。

iPhone 示例：服务器目录地址 `https://example.com/dav/`，用户目录 `alice`。实际同步位置与直接填写完整地址相同。用户目录独立写入本机配置文件，切换目录时使用独立的本地同步空间。

- 用户甲：`https://example.com/dav/alice/`
- 用户乙：`https://example.com/dav/bob/`
- 同一用户的 Android TV 和 iPhone 填写同一地址。

实际文件分别为上述目录下的 `fongmi-sync-v1/state.json`。旧地址保持原来的存放位置，无需迁移。

首次同步或连接测试先创建末级目录；遇到 HTTP 409（缺少父目录）时逐级创建父目录，再重试。目录已存在时接受 HTTP 405。认证失败、无权限、重定向等仍返回错误，不会绕过权限，也不删除已有目录。

不同文件夹提供数据分区。共用同一账号且拥有所有文件夹权限时，不能阻止用户访问其他目录；需要权限隔离时，应由 WebDAV 服务端为各账号限定目录访问范围。
